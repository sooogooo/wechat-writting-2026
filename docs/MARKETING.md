# WeChat Writing — Marketing Copy

> 内部用也好,公开发布也好,这里提供 5 个分发渠道的成品文案与使用建议。所有文案都遵守 SKILL.md 的语气约定:克制、有判断、不喊口号。

## 0. 仓库定位一句话 (Source-of-truth blurb)

可以复用到任何渠道的简介,首句就是定位,末句是承诺。

> 一个把"资深医美 / 体相 / 医美机构运营评论者"的写作约束蒸馏进 prompt 模板的开源 skill。三种模式:起标题 / 写正文 / 深度精修。能跨 Claude Code、Codex CLI、Cursor、Continue、Cline 使用。让 AI 写得克制,而不是写得更多。

字数:约 90 字。可拆。

短版(45 字):**一个把写作约束蒸馏进 prompt 的开源 skill,让 AI 写得克制,而不是写得更多。**

超短版(20 字):**让 AI 写得克制的写作 skill。**

## 1. 微信公众号推文 (主战场)

**标题备选 (3 个,从传播/判断/克制三档各取一个)**:

1. 我把一个资深医美评论者的写作约束,做成了一个开源 skill
2. 你以为 AI 写作的问题是没有 prompt,其实是 prompt 里没有禁区
3. 一个写了三年公众号的人,把判断做成了 skill

**封面建议**:
- 配色:克制 / 接近黑的白 / 一道细线
- 不放文案截图;放一个语义化的视觉锚(比如判断线的截面,或一道被切掉一半的对话框)
- 排版工具:同篇不超过 2-3 种字体

**正文结构 (草案)**:

开头:
> 公众号写作有三种低质量状态:套话模板、行业背景铺陈、句子金句化。改到第三稿时,大家意识到 — 问题不在模型本身,而在 prompt 里没有禁区。

中段:
> 把一个资深评论者的写作约束蒸馏进 SKILL:三种模式(title / draft / polish)、禁区列表、机制层解释的最低标准、医美 / 体相 / 机构运营各自的判断框架。它不是 prompt 集合,是"判断"。免费开源,跨平台。

结尾:
> 仓库地址在文末。如果你的公众号也卡在第三稿,可以试试。用了觉得有效,告诉我;用了觉得鸡肋,告诉我为什么。

**互动钩子 (公众号特有的"在看 / 点赞 / 评论"引导)**:

不用"求点赞"语气,改成:
> 如果你也写过改三稿的公众号文章,在评论区留一个标题,我用这个 skill 帮你起 10 个新标题。挑 3 个留言写进复盘。

## 2. 知乎回答 / 想法 (针对: "有什么 AI 写作工具推荐" 类问题)

**回答开头**:
> 我不做"AI 能不能写公众号"这类讨论。我做了个开源 skill 解决我自己的问题,思路可能对你有参考。

**回答正文**:
- 不要罗列工具
- 说一个具体场景:我第三次改稿时遇到什么问题
- 把 skill 的核心思路讲清楚(为什么 prompt 不是 prompt, 是"禁区 + 判断")
- 仓库地址 + 一句话安装方式
- 主动说出局限:不擅长俏皮短句;过度克制;非医美 / 体相领域效果一般

**知乎签名档**:
> 作者:sooogooo · 医美 / 体相 / 公众号三种身份交叉写东西的人

## 3. 即刻 App (短帖 + 评论互动)

**第一帖**:
> 把 3 年公众号改稿经验蒸馏成 1 个开源 skill。
> 3 个模式:起标题 / 写正文 / 精修。
> 跨 5 个 AI CLI 和 IDE:Claude Code、Codex、Cursor、Continue、Cline。
> 一个核心思路:让 AI 写得克制,而不是写得更多。
> github.com/sooogooo/wechat-writting-2026

**互动回复模板**:
- 有人问"和 XX 工具比呢" → "没用过 XX;但这个 skill 的关键不是 prompt,是禁区。如果你的 prompt 里没有禁区,那任何大模型都会陷入套话。"
- 有人问"商业模式" → "MIT 开源,没打算变现。如果后续有公众号 / 医美机构 / 医美 IP 写作需求的合作,可能。"
- 有人指出"还是 AI 味" → "写一段你看了觉得 AI 味的,我帮你诊断哪里违反 skill,可以 fork 写得更狠。"

> github.com/sooogooo/wechat-writting-2026

(280 字以内,关键:不喊口号,不夸大)

1/ The skill — open source, MIT.
2/ Why I built it. (改稿三遍的痛)
3/ Why this isn't another prompt collection. (写作约束 ≠ prompt 集合)

## 5. 小红书 / 公众号矩阵 (内容创作者社群)

**笔记开头 (口语化)**:

> 改了三年的稿,我做了一件小事:把"什么不能写"的清单蒸馏成了一个 skill,免费开源。能用在 Claude、Codex、Cursor 这类 AI 工具里。笔记有点长,但比笔记更重要的是你看完能用的判断。

**正文风格**:
- 用 emoji 分隔段落 (与 SKILL 自己的克制原则不同 — 这是渠道风格适配,不是 skill 本身的原则)
- 多用"姐妹 / 朋友 / 我自己"的代入句
- 截图仓库主页 + 三种模式触发示例
- 结尾 "评论扣 'skill',我把三种模式的对比表发给你"

(注意:小红书风格 ≠ skill 写作风格,这是渠道适配,不是降格)

## 6. 不推荐使用的渠道和文案类型

| 渠道 / 类型                 | 不推荐原因                                    |
| --------------------------- | --------------------------------------------- |
| 抖音 / 视频号口头植入       | 视频内容需要"情绪",与 skill 克制哲学冲突     |
| 播客脚本 (聊天)             | 信任建立需要具体案例;skill 是工具不是故事      |
| LinkedIn 长篇 essay         | 受众错配                                     |
| Reddit r/LocalLLaMA / PromptEng | 不属于英文 native 写作领域;社区偏好不同 |
| "AI 写作课程" 软广           | 与 skill 的开源承诺冲突                       |

## 7. 推广节奏建议 (前 4 周)

| 周次 | 动作                                                                  |
| --- | ----------------------------------------------------------------------- |
| W1  | 微信公众号首发 + GitHub Release v0.1.0                                   |
| W2  | 即刻 + 知乎答复(找 3 个现存的"AI 写作工具"问题下面认真回答)            |
| W3  | X 发英文 thread + 联系 3–5 位 AI / 写作垂类账号 review                  |
| W4  | 根据反馈出 v0.2.0 + 第二轮知乎答复 / X thread                          |

冷启动期不强求一次爆款,核心是:把仓库的卡片页(readme 渲染页)做厚,任何渠道进来的访客能在 60 秒内明白"我能拿它干什么"。

## 8. 数据指标 (发布后第一个月可追踪)

- **GitHub**: stars / forks / issue 数 / clone 数
- **公众号**: 阅读 / 在看 / 评论 / 关注转化
- **即刻**: 点赞 / 收藏 / 评论
- **知乎**: 回答赞同 / 收藏 / 关注
- **跨平台安装触发数**:如果用户有 telemetry 且愿意分享,可以匿名收集触发统计(慎用)

不追的指标:公众号阅读量(单篇)、点赞、转发率。这些与 skill 质量的相关性弱,与渠道权重、推荐算法相关。
